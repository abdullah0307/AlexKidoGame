Reactorcore Art (RC Art)
==
PACK: Smooth Physics Props

--

Pixel-art sprites pack depicting multiple common physics objects and gameplay interactables, including a few sports balls of different kinds.

--

Objects are roughly measured for a '32 pixels per meter' standard. An average adult human would be about 50-60 pixels tall.

--

By default in image import settings, all sprites/textures have been set to 32 pixels per unit and using a point filter so they appear crisp.
